Unified Workspace & Takeover

One roof for every agent—and one-click takeover for existing sessions

No need to open separate Claude, Codex, or Antigravity desktop apps alongside terminal tabs. Everything lives here—and sessions already running elsewhere can be taken over cleanly anytime.

  • Parses native JSONL transcripts into clean plans, tool steps, and diffs—with live xterm.js terminal view one tap away (and terminal prompts turned into tap cards)
  • Auto-discovers sessions started outside Collie in iTerm, VS Code, tmux, SSH, or desktop apps for live viewing and one-click takeover

Architecture

One always-on hub, every machine dials in

Run one hub on an always-on machine. Other computers run collie node to dial out to the hub over multiplexed tunnels—no open ports, no SSH. Agents live in herdr, so closing your browser never stops them.

Single Go binarySQLite, xterm.js, and embedded web UI included—zero external CDN
Zero-port outbound tunnelsMultiplexed yamux over IPv4 & pure IPv6 with automatic reconnect
Multi-hub federationRun one hub per isolated network and view every fleet in one sidebar
Rolling fleet updatesOne click in Web UI or `collie update --all` upgrades remote nodes first, then the hub—running agents stay untouched

Quick Start

Up and running in 30 seconds

macOS, Linux (amd64 / arm64), and Windows via WSL2 (Ubuntu/Debian). Verifies SHA-256 checksums, installs herdr if missing, registers a background service (launchd or systemd --user), and prints a QR code ready to scan.

Run on an always-on machine, then scan the terminal QR code from your phone to pair.

curl -fsSL https://lihuanyu0w0.github.io/collie/install.sh | sh -s -- hub

Run on any other computer. Copy the hub URL and pairing code from Devices → Connect a computer—dials outbound, no open ports.

curl -fsSL https://lihuanyu0w0.github.io/collie/install.sh | sh -s -- node --hub http://<hub>:7788 --code <code>

Verifies SHA-256, replaces the binary atomically, and restarts active systemd --user / launchd services (alias: collie upgrade). Add --check to inspect or --all to upgrade the whole fleet.

collie update

Install only the collie binary to ~/.local/bin without registering a service.

curl -fsSL https://lihuanyu0w0.github.io/collie/install.sh | sh

Requires Go 1.25+. Run the same script inside the repo to build locally; pass hub or node --hub … --code ….

git clone https://github.com/lihuanyu0w0/collie.git
cd collie
sh docs/install.sh hub
