Why Collie

Your agents keep shipping while you step away

Everything runs on your own computers. Collie keeps the whole fleet visible, steer-able, and quiet until it genuinely needs you.

One entry, a fleet of agentsTell Collie what you need. It picks the right agent, model, and machine, dispatches workers in parallel, and rolls results back into one chat.

Super-agent

Say one sentence, Collie orchestrates

Talk to a single persistent router on your hub. It splits tasks across isolated workers, tracks progress, and surfaces concise updates when they matter.

  • Picks the agent, machine, and model automatically based on your context and notes
  • Reply chains open in a resizable thread drawer with direct image paste, drag-and-drop uploads, and live worker status pills
  • Unread-anchored main feed keeps your reading spot steady during bursts of worker reports

Direct control

Launch a fresh agent anywhere—pick its kind, working directory, and model, and give it an opening task. Inspect every plan and tool call in structured chat, with the active model in the header.

  • Discovers sessions running in iTerm, VS Code, tmux, SSH, and desktop apps—view live or take over in one click
  • Flip to live xterm.js screen output or wrapped logs whenever you want raw terminal truth

Always-on & Memory

Events flow in, knowledge compounds

Chat messages, GitHub PR reviews and CI alerts, zero-public-IP Feishu/Lark WebSocket cards, webhooks, and cron timers all land in one inbox. Subscribed workers get thread updates directly; the rest go to Collie.

  • Built-in GitHub integration plus pluggable local CLI providers, backed by 0600-protected secret storage
  • Structured memory (preferences, active tasks, project notes) tidied nightly—and portable via one-click ZIP export/import

Architecture

One always-on hub, every computer dials in

Run one hub on an always-on devbox. Other machines run collie node to dial out to the hub; phones and browsers connect only to the hub. Agents live in herdr, so closing your tab never stops them.

Single binaryWritten in Go with SQLite, xterm.js, and UI embedded—zero CDN required
Dual-stack outbound tunnelMultiplexed yamux over IPv4 & pure IPv6 with automatic reconnect
Multi-hub federationRun a hub per isolated network and view every fleet in one sidebar
One-click fleet updatesUpgrades remote nodes first, then the hub—running agents stay untouched

Install

Running in two minutes

macOS & Linux (amd64 / arm64). Verifies SHA-256 checksums, registers a background service (launchd or systemd --user, falling back to nohup), detects IPv4/IPv6 addresses, and installs herdr if missing.

Run on an always-on machine, then scan the terminal QR code from your phone to pair.

curl -fsSL https://lihuanyu0w0.github.io/collie/install.sh | sh -s -- hub

Run on any other computer. Copy the hub URL and pairing code from Devices → Connect a computer—dials outbound, no open ports.

curl -fsSL https://lihuanyu0w0.github.io/collie/install.sh | sh -s -- node --hub http://<hub>:7788 --code <code>

Install only the collie binary to ~/.local/bin without registering a service.

curl -fsSL https://lihuanyu0w0.github.io/collie/install.sh | sh

Requires Go 1.25+. Run the same script inside the repo to build locally; pass hub or node --hub … --code ….

git clone https://github.com/lihuanyu0w0/collie.git
cd collie
sh docs/install.sh hub
