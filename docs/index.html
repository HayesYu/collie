Collie
怎么用 GitHub

在手机上放牧
你的编程 agent

Collie 把跑在各台电脑上的 Claude Code、Codex、Antigravity 收到一个网页里：看对话、发消息、处理确认框，需要你的时候叫你一声。

在一台常开的开发机上运行，装成后台服务。之后用手机扫终端里的二维码就能登录。

curl -fsSL https://huanyu1w1.github.io/collie/install.sh | sh -s -- hub

在其他电脑上运行。hub 地址和配对码在 hub 的「设备 → 连接一台电脑」里拿；电脑主动连 hub，不用开端口。

curl -fsSL https://huanyu1w1.github.io/collie/install.sh | sh -s -- node --hub http://<hub>:7788 --code <配对码>

只把 collie 装到 ~/.local/bin，不装服务。

curl -fsSL https://huanyu1w1.github.io/collie/install.sh | sh

macOS、Linux（amd64 / arm64）。服务用 launchd 或 systemd --user；下载会校验 SHA-256。查看脚本

怎么用

  1. 开发机上起 hub先装好 herdr 和它的 agent 集成（herdr integration install claude），再跑上面的「做 hub」。
  2. 手机扫码扫终端里的二维码，或在「设备 → 连接手机或平板」里扫。每台设备一个令牌，随时可以移除。添加到主屏幕后就像一个 app。
  3. 其他电脑加入笔记本在 NAT 后面也行：collie node 主动连上 hub，断线自动重连。

能做什么

对话视图直接读 agent 自己的会话记录，终端变成可读的对话；长对话可以往前翻。
决策卡片agent 停在确认框时，问题和选项变成一张卡片，点一下就回。
多台电脑一个 hub 合并所有电脑的 agent，侧栏按电脑分组，新建 agent 时选在哪台跑。
其他终端里的会话iTerm、VS Code、tmux 里直接跑的 claude / codex / agy 也能看到，可以在 herdr 里接管。
Super-agent只和 Collie 说话：Router 把活拆给并行的 worker，结果作为事件回到对话里。
接入外部事件GitHub、飞书 webhook 和定时器都是 Trigger，按来源策略过滤后交给 Router。

结构

 手机 / 平板 / 浏览器 ──HTTP──▶  hub（开发机：collie + herdr）
                                  ▲   ▲
               collie node ──出站─┘   └─出站── collie node
               （本地 Mac + herdr）           （另一台机器）

单个 Go 二进制，前端内嵌，内网不需要访问 CDN。状态存在 SQLite（~/.collie/herd.db）。内网里是明文 HTTP，跨网络请放在 VPN / Tailscale 或 HTTPS 反向代理后面。
